Two-factor authentication

Use an authenticator app (for example Google Authenticator, Microsoft Authenticator or 1Password). With two-factor on, banning, reinstating, changing roles and exporting CSV each ask for a fresh 6-digit code.

In your authenticator app choose Enter a setup key and type this key. Keep it private: it is shown only once.
